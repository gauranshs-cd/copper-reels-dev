# SEO-Optimized Page Building Plan for Copper Reels

## SEO Strategy Overview

### Target Keywords
- Primary: "AI YouTube script generator", "YouTube content strategy", "viral video creator"
- Secondary: "YouTube automation tools", "content creation AI", "video script templates"
- Long-tail: "how to create viral YouTube videos", "AI powered YouTube content creator", "YouTube growth system"

### SEO Implementation Guidelines
1. **URL Structure**: Use clean, keyword-rich URLs (e.g., /youtube-script-generator)
2. **Meta Tags**: Unique title (50-60 chars) and description (150-160 chars) per page
3. **Headers**: H1 with primary keyword, H2-H3 with semantic variations
4. **Internal Linking**: Cross-link related content with descriptive anchor text
5. **Schema Markup**: Add VideoObject, FAQPage, Organization schemas
6. **Page Speed**: Target <2s load time, optimize images, lazy loading
7. **Mobile-First**: Responsive design, touch-friendly CTAs
